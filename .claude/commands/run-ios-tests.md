Run the complete iOS test suite for the Wikipedia app following these steps:

1. Check that an iOS device is connected and running
2. If no device is running, start the iPhone 16 Pro simulator
3. Read the test conventions from `.claude/maestro-testing.md`
4. Read the report template from `.claude/report-template.md`
5. Verify all test flows in `.maestro/ios/` have screenshots configured
6. Run all iOS test flows with screenshot capture
7. Generate a comprehensive HTML report following the template guidelines
8. Include all embedded screenshots in the report
9. Provide the path to the generated report

Follow all conventions from the `.claude/` configuration files.
